## 本次更新（0.4.4）

### 开屏动画：只在「安装后第一次」和「版本更新后第一次」出现

- **必须点「开始使用」才进入**主界面（回车 / 空格等效）。开屏不再自己走掉，你可以看清那个画面。
- **之后每次启动都不再出现开屏**，直接进主界面；卸载重装、或更新到新版本后会再出现一次。
- 设置页里的「开屏动画 → 重放」已移除（不再提供手动重放）。

### 性能：两处大优化

| 位置 | 改动 | 实测（本机 180Hz / release） |
| --- | --- | --- |
| 开屏 | 4 团漂移光斑换成静态径向渐变；霜层由实时模糊（backdrop-filter）改为静态白；去掉全窗噪点混合层 | **10.6~13.1% → 3.4%** |
| 首页氛围光雾 | 去掉 canvas 上的静态滤镜（非整数缩放的逐帧重采样） | **9.56% → 1.99%** |

开屏的观感与原设计基本一致（像素比对 均值 5.8~6.9/255、p95 15），唯一区别是光斑不再缓慢漂移。

### 修复

- 开屏有时**停在原页既不进入也不出按钮**：自动进入的 4 秒计时会被父组件重渲染反复重置。
  本版已把「进入」改为必须点击，这个问题不复存在。

### 支持格式一览

| 扩展名 | 编码 / 容器 | 解码器 |
| --- | --- | --- |
| .mp3 | MPEG 音频（MP3） | symphonia |
| .flac | FLAC | symphonia |
| .wav | PCM / ADPCM（RIFF） | symphonia |
| .aiff | PCM（AIFF） | symphonia |
| .caf | PCM（CAF） | symphonia |
| .ogg / .oga | Ogg 容器内的 Vorbis | symphonia |
| .m4a / .m4b | MP4 容器内的 AAC 或 ALAC | symphonia |
| .opus | Ogg Opus | opus-pure（自行接入） |
| .aac | 裸 AAC / ADTS 流 | 自写 ADTS 解封装 + symphonia 的 AAC 解码器 |
| .dsf / .dff | DSD | 自研：1-bit 查表低通 + 整数抽取转 PCM |

**暂不支持**：APE、WavPack、TAK、Musepack(MPC)、WMA(ASF)、Speex、RealAudio，以及 CUE 整轨分轨。
