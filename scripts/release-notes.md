## 本次更新（0.4.0）

### 重采样换成多相 sinc —— 修掉一个一直存在的音质短板

rodio 自带的采样率转换器在源码注释里写得很直白：**上采样用线性插值、下采样直接丢样本**（没有抗混叠
滤波）。而共享模式下设备采样率就是你在 Windows 里设的那个（本机是 192 kHz），于是**每一首**
44.1 kHz 的曲目都被这样转换过。

0.4.0 换成自研的**有理数多相 windowed-sinc** 重采样：

- 按「曲目采样率 → 设备采样率」一次算到位，中间不经过任何中间采样率、不级联；
- 每个相位单独归一化（直流增益精确为 1，不会有电平起伏）；
- 相位表按采样率对设计并缓存，同一对只建一次；
- 独占模式按曲目率协商成功时**完全不重采样**，一分钱不多花。

实测（同一条 96 kHz→48 kHz、超出输出奈奎斯特的 30 kHz 信号，会折成 18 kHz）：

| | 折叠出来的 18 kHz 幅度 |
| --- | --- |
| 旧（rodio 自带转换器） | **0.99999**（满幅混叠） |
| 新（多相 sinc） | **0.00000** |

其它关卡：15 kHz 的镜像压到 0.00036（−69 dB）；1 kHz 幅度 0.5002（期望 0.5）；
900/1100 Hz 泄漏 0.0006（>800 倍抑制）；直流增益 1.0000000；10 秒长流无漂移。

代价（release 实测，立体声占单核比例）：44.1k→48k 约 0.45%、→96k 约 0.9%、→192k 约 1.8%。

### 设置页新增「采样率」

设置 →「独占输出」里可以直接看到当前发生了什么，不用再翻控制台：

- `解码 44100 Hz → 输出 192000 Hz（多相 sinc 重采样）`
- `解码 44100 Hz → 输出 44100 Hz（直通，未重采样）` ← 独占模式协商成功时

### 支持的格式一览

| 扩展名 | 编码 / 容器 | 解码器 |
| --- | --- | --- |
| .mp3 | MPEG 音频（MP3） | symphonia |
| .flac | FLAC | symphonia |
| .wav | PCM / ADPCM（RIFF） | symphonia |
| .aiff | PCM（AIFF） | symphonia |
| .caf | PCM（CAF） | symphonia |
| .ogg / .oga | Ogg 容器内的 Vorbis | symphonia |
| .m4a / .m4b | MP4 容器内的 AAC 或 ALAC | symphonia |
| .opus | Ogg Opus | opus-pure（自行接入） |
| .aac | 裸 AAC / ADTS 流 | 自写 ADTS 解封装 + symphonia 的 AAC 解码器 |
| .dsf / .dff | DSD | 自研：1-bit 查表低通 + 整数抽取转 PCM |

**暂不支持**：APE、WavPack、TAK、Musepack(MPC)、WMA(ASF)、Speex、RealAudio，以及 CUE 整轨分轨。

### 输出说明

- **共享模式**：按设备当前采样率做一次多相 sinc 转换（0.4.0 起不再是线性插值）。
- **独占模式**：优先按曲目采样率协商，争取 bit-perfect；设备不支持时自动回退共享并在设置页说明原因。
- DSD 的原生直出（DoP）需要 DAC 支持 176.4kHz 独占，属于后续版本。
