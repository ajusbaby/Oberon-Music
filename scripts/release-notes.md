## 本次更新（0.4.10）

### 侧栏图标实心化
Home / Library / Favorite 三枚主导航图标换成实心块面，与实心的 Albums 圆盘统一；未收藏状态的线框心形仍保留在播放条与曲目行里，收藏与否照样一眼可辨。

### 窗口边框四边一致
窗口外缘的描边加深一档，并在边线内侧补了一道 1px 高光 —— 四个边内侧底色本来是侧栏白、主区灰、播放条霜面三个值，同样的线压在灰底上会比压在白底上显细，垫上亮线之后四边浓度拉平，右下与右侧不再看着比左侧淡。深色主题同步了一遍。
