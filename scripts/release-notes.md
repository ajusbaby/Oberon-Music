## 本次更新（0.4.14）

### 自定义字体终于能用了
设置 → 歌词排版下面多了一整块「歌词字体」：把 .ttf / .otf / .ttc / .woff / .woff2 拖进字体库就能用，单个上限 64MB，重复导入同一份文件不会重复占位。

字体存的是文件哈希，不是文件名——所以你事后改名、换目录都不影响已经选好的档案。删字体时会一起清掉文件、索引和引用它的档案，不会留下一条点不动的空记录。

### 六种语言各用一个字体
简体中文 / 繁体中文 / 日文 / 韩文 / 拉丁字母 / 符号与 Emoji，每个档案独立挑主字体，还能再挑几个备用字体接在后面。中日共用汉字，但判定按证据加权走：假名、谚文这类专属文字出现即定音，纯汉字行跟着整首歌的语言走——日文歌里夹的中文翻译行不会被硬拽去用日文字体。

每首歌还能在歌词页顶栏单独改语言（顶栏右侧那个「语言」），判错了只影响这一首，不用动全局设置。

### 缺字不装没事
字体里没有某个字时，那一段会落回同语言的系统字体，并画一条点状下划线（可在设置里开关「标注实际字体来源」）。点一下就能看到具体缺哪个码位，方便回头换字体。

### 顺手修的
歌词页那个「语言」下拉原来是系统原生菜单，白底直角跟流光完全不搭；换成自绘的玻璃面板，键盘上下键、回车、Esc 都能用，展开时顶栏也不会自己淡出。
删除字体时，已加载进内存的字体实例现在会一起摘掉，不再占着不放。
