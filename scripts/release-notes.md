## 本次更新（0.4.7）

### 歌词字体不再可配置 —— 只留排版

此前设置页可以按「西文 / 中文 / 日文 / 韩文」四个槽位分别挑字体，还能上传 ttf（内置 Ephesis、马善政两款）。
实践中这套配置带来的问题多于收益：

- 中文歌里出现一个「・」或拖长的「ーー」、或者夹进一句日语，整首歌会被判成日文 → 汉字落到日文字体上，
  一行里两种字形、两种字号、两种笔画，看上去就是「粗细大小不统一」；
- 上传自己的字体还要自己判断缺字，缺字时逐字回退，同样会破坏一行的统一性。

本版**移除**了字体选择、上传 / 删除字体、缺字覆盖检测与「缺字时」策略。歌词正文固定使用系统字体栈，
按语言选链（西文 / 中文 / 日文 / 韩文），一行一个字重、一个字号。

**保留**：

- 字号：滑杆 + 小 / 标准 / 大 / 特大 预设；
- 粗细：细 / 常规 / 中等 / 粗体；
- 语言匹配：一致性优先（纯汉字行一律按中文，推荐）/ 准确优先（跟随整首歌的语言）。

顺带：内置的马善政书法体（5.9 MB）在界面里已无使用者，不再打进安装包 —— **安装包体积减少约 6 MB**。

### 歌词页背景

歌词页背景的视觉设计参考了 **Salt Player**（Moriafly 出品的 Android 本地音乐播放器）：
封面高斯模糊铺底 + 暗化遮罩 + 逐行浮起的歌词。Oberon 为独立实现（纯 CSS 模糊层 + React 行渲染）。

### 支持格式一览

| 扩展名 | 编码 / 容器 | 解码器 |
| --- | --- | --- |
| .mp3 | MPEG 音频（MP3） | symphonia |
| .flac | FLAC | symphonia |
| .wav | PCM / ADPCM（RIFF） | symphonia |
| .aiff | PCM（AIFF） | symphonia |
| .caf | PCM（CAF） | symphonia |
| .ogg / .oga | Ogg 容器内的 Vorbis | symphonia |
| .m4a / .m4b | MP4 容器内的 AAC 或 ALAC | symphonia |
| .opus | Ogg Opus | opus-pure（自行接入） |
| .aac | 裸 AAC / ADTS 流 | 自写 ADTS 解封装 + symphonia 的 AAC 解码器 |
| .dsf / .dff | DSD | 自研：1-bit 查表低通 + 整数抽取转 PCM |

**暂不支持**：APE、WavPack、TAK、Musepack(MPC)、WMA(ASF)、Speex、RealAudio，以及 CUE 整轨分轨。
