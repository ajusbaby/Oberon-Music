## 本次更新（0.4.9）

### 搜索改成独立浮层
点顶栏搜索框或按 Ctrl K 弹出，不离开当前页面。↑↓ 选择、Enter 播放、Esc 或点外面关闭；歌曲 / 专辑 / 艺术家 / 播放列表分组显示。

### 新增「Albums」页
侧栏第二项改为专辑墙，一屏看完所有专辑，悬停封面播放整张。

### 列表与界面细节
- 当前播放行用橙色竖条 + 暖色底 + 橙色标题标记，与鼠标悬停彻底分开
- 窗口外缘、侧栏、播放条各补一道细边界，不再糊成一片
- 键盘操作有独立焦点环，表头可点可聚焦
- 窄窗自动收起专辑列；深色主题补齐对比度

### 空间音效默认关闭
新装默认干声，需要混响时在设置里自己打开。

### 清理
删除改版后无人调用的样式与模块。

### 安装 / 更新
- **全新安装**：下载下方的 Oberon_0.4.9_x64-setup.exe
- **已装旧版**：应用内「设置 → 数据与关于 → 检查更新」自动更新
