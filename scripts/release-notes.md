## 本次更新（0.4.15）

### 听歌记录不再怕重装
统计不再是「应用里的一份临时账本」：每次听完一首都会同时写进缓存和磁盘，另存一份文档镜像，设置里还能导出、导入备份。

卸载重装后把备份并回去，历史会按文件路径哈希自动对齐——同一首歌换过目录也认得出，不会出现一首歌两条记录、也不会把旧数据覆盖成新数据。

### 设置页的下拉菜单全部重画
之前那批下拉用的是 Windows 原生菜单，白底直角、和应用的流光质感完全不搭。现在统一换成自绘面板：白卡圆角、发丝描边、分层阴影，当前项加粗带勾，鼠标悬停有反馈，↑↓ / Home / End / 回车 / Esc 全都能用。

播放输出、输出模式、独占音量、独占采样率，以及六种语言档案的「主字体 / 备用字体」，现在都是这一套。

### 导入字体按钮显眼了
「导入字体文件」改成黑底白字、带加号，放在字体库标题右侧，不用再找。

### 顺手修的
- **备用字体下拉整条空白**：旧数据里主字体和备用字体存成了同一个，而选项列表会把主字体滤掉，于是下拉框什么都不显示。现在读取时就把这种脏数据归一化，界面直接显示「无备用字体」，不用手动清。
- **预览里的缺字叠成一团**：主字体没有、系统链也没有的字（比如 𠀀）原本会画成零宽豆腐块、互相重叠。现在缺字单独成小块并加虚线下划线；整段缺字（比如韩文档案里的中文样句）不铺底色，只留下划线。
- **语言弹框细节**：「自动判定」和六种具体语言之间加了一条发丝分隔线，选中项有底色，鼠标悬停不再弹出系统原生提示条。

- **已装旧版**：应用内「设置 → 数据与关于 → 检查更新」自动更新
