## 本次更新（0.4.8）

### 音乐厅氛围

设置页新增独立一节「音乐厅氛围」，只有一个开关：打开后所有曲目共用一个声场，切歌不断尾巴，关掉就回到原始信号（零额外开销）。

实现是挂在播放总线上的 Freeverb（8 路 comb + 4 路 allpass，左右声道错开 23 个采样），阻尼按本机采样率实时归一化，44.1 / 48 / 96 kHz 下混响时间都稳定在 4.3 秒左右。总线级挂载意味着换歌、调音量、切输出设备时混响尾巴不会被截断；送到设备前还有一道软限幅，满刻度输入也不会削顶。

### 窗口按屏幕自适应

旧版把 1267×902 写死在配置里，最小尺寸 1152×768。14 寸笔记本开 150% 缩放时逻辑分辨率只有约 1280×680，装好就是上下出屏，而且最小高度比屏幕还大，想拖小都拖不动。

本版启动时先读显示器工作区（已扣掉任务栏），把窗口夹进可用区域再显示，最小尺寸同步降到 960×600；工作区比这还小的机器（远程桌面、老上网本）会继续把下限压低，保证窗口始终能完整看见。

### 悬停不再弹黄色气泡

上一版给按钮挂了一句功能解释，鼠标停上去会弹系统气泡，停在播放列表上尤其碍眼。本版把这批 `title` 去掉或转成 `aria-label`：读屏软件仍能念出按钮名字，视觉上不再有浮层。因文本截断而显示完整内容的那批 `title` 保留不动。

### 视觉微调

- 封面取色：纹理 72×72 → 76×76，饱和度 2.5 → 2.3，白纱上限 0.9 → 0.88，浅色封面的页面底色更贴近封面本身；
- 歌词页留白：左右 30 → 32，上下 16 → 18。

### 内部清理

删除 9 个已经没人调用的前端导出（4 个 IPC 包装，以及 `formatBytes` / `num` / `hexToTriple` / `prefetchCovers` / `frameBudgetInfo`）和两个一次性脚本。现在 `tsc --noUnusedLocals --noUnusedParameters` 与 `cargo build` 的未使用检查都是零告警。

- **已装旧版**：应用内「设置 → 数据与关于 → 检查更新」即可自动更新
