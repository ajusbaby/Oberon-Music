## 本次更新（0.4.3）

### 新增开屏动画

启动时先看到一屏磨砂材质的开屏：四团彩色光斑缓慢漂移，品牌手写体「Oberon music」
从左往右像书写一样刷出，随后浮出「开始使用」。

- **首次启动**：停在开屏页，点「开始使用」（或按回车 / 空格）进入。
- **之后启动**：书写结束后自动进入，不用再点。
- **开屏期间主界面完全不可见**（不透明底色 + 磨砂层），不会出现「先闪一下主界面」。
- **低功耗模式**：光斑漂移与整屏背景模糊都会停掉，换成静态渐变。
- **系统开启「减少动态效果」**：直接呈现书写完成的静态画面。
- 想再看一次：**设置 → 数据与关于 → 开屏动画 → 重放**。

### 修复：多声道文件下混（5.1 / 7.1 → 立体声）

以前把 5.1 的 FLAC 放到立体声输出上，内部用的是「取前两个声道、其余直接丢弃」的转换 ——
**中置（人声、主奏通常在那儿）、低频、两个环绕全被静默扔掉**，而且没有任何提示。

现在按 **ITU-R BS.775** 正式下混：

```
L = FL + 0.707·FC + 0.707·BL + 0.5·LFE
R = FR + 0.707·FC + 0.707·BR + 0.5·LFE
```

实测（一个**只有中置声道有信号**的 5.1 文件）：修复前输出峰值 **0.0000**（完全听不到），
修复后 **0.7071**（中置完整进入左右声道）。

- 覆盖 3 / 4 / 5 / 6 / 7 / 8 声道的常见布局；
- 输出设备本身是多声道时不介入，原样直通；
- 布局推断不出来的声道数保持旧行为，并在日志里给出警告。

### 支持的格式一览

| 扩展名 | 编码 / 容器 | 解码器 |
| --- | --- | --- |
| .mp3 | MPEG 音频（MP3） | symphonia |
| .flac | FLAC | symphonia |
| .wav | PCM / ADPCM（RIFF） | symphonia |
| .aiff | PCM（AIFF） | symphonia |
| .caf | PCM（CAF） | symphonia |
| .ogg / .oga | Ogg 容器内的 Vorbis | symphonia |
| .m4a / .m4b | MP4 容器内的 AAC 或 ALAC | symphonia |
| .opus | Ogg Opus | opus-pure（自行接入） |
| .aac | 裸 AAC / ADTS 流 | 自写 ADTS 解封装 + symphonia 的 AAC 解码器 |
| .dsf / .dff | DSD | 自研：1-bit 查表低通 + 整数抽取转 PCM |

**暂不支持**：APE、WavPack、TAK、Musepack(MPC)、WMA(ASF)、Speex、RealAudio，以及 CUE 整轨分轨。
