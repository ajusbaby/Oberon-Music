## 0.4.18

修掉歌词页长时间停留后切句发卡：`.sl-line` 不再过渡 `font-size`（每帧改一点字号会让整页重新排版、并让每个中间字号都成为一套新的 CJK 字形缓存——低配机上单次切句最差帧 55.6ms，修复后 11.1ms），放大仍按 `--sl-lead-scale` 一次性到位；同时修掉窗口被任务管理器之类抢走键盘焦点时帧循环被砍到 11fps 的问题（现在失焦时只要歌词还在移动就全速，静止才降到 30fps）。新增 `npm run check:paint` 静态检查，防止有人把字体类属性再塞回过渡里。另新增「设置 → 歌词排版 → 帧率」开关：默认固定 60 帧，可切到「跟随屏幕」吃满显示器刷新率（切句位移采样更细，代价是切句瞬间 GPU 占用约 2 倍）。

全新安装：`Oberon_0.4.18_x64-setup.exe` ｜ 已装旧版：设置 → 数据与关于 → 检查更新
