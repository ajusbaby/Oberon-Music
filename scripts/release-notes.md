## 0.4.20

开源协议补上了：MIT —— 商用、修改、闭源再发布、打包进自己的产品都行，只要保留版权声明（见仓库根目录 `LICENSE`）。版本号 0.4.20。

统计页口径也改准了：一首歌必须完整听完（到结尾 0.4–2 秒容差内）才记一次播放，中途切走只累计时长、列表里显示「未听完」；同时删掉了「听歌数」「收听天数」两个指标卡片，页面只留总时长、柱状图和每首歌的「N 次」。

**更新签名密钥换了**：打包机上原来的私钥已经找不回来，这次改用新密钥签名。所以已装 0.4.19 的机器点「检查更新」会报验签失败（不是网络问题），手动下载下面的安装包覆盖装一次即可；从 0.4.20 起自动更新恢复正常。

## 0.4.19

首页封面流切卡的 GPU 尖峰降下来了：`.cf-card` 的过渡不再带 `box-shadow` / `border-color`，阴影和描边改为瞬间到位（肉眼看不出来，因为 460ms 的滑动还在跑）。切卡期间真实的 GPU 忙时从 45–55 ms/秒降到 25–30 ms/秒（约 −44%），光栅化 −30%、绘制 −25%，滑动、淡入、当前卡的发光与放大全部保持原样。

全新安装：`Oberon_0.4.19_x64-setup.exe` ｜ 已装旧版：设置 → 数据与关于 → 检查更新

## 0.4.18

修掉歌词页长时间停留后切句发卡：`.sl-line` 不再过渡 `font-size`（每帧改一点字号会让整页重新排版、并让每个中间字号都成为一套新的 CJK 字形缓存——低配机上单次切句最差帧 55.6ms，修复后 11.1ms），放大仍按 `--sl-lead-scale` 一次性到位；同时修掉窗口被任务管理器之类抢走键盘焦点时帧循环被砍到 11fps 的问题（现在失焦时只要歌词还在移动就全速，静止才降到 30fps）。新增 `npm run check:paint` 静态检查，防止有人把字体类属性再塞回过渡里。另新增「设置 → 歌词排版 → 帧率」开关：默认固定 60 帧，可切到「跟随屏幕」吃满显示器刷新率（切句位移采样更细，代价是切句瞬间 GPU 占用约 2 倍）。

全新安装：`Oberon_0.4.18_x64-setup.exe` ｜ 已装旧版：设置 → 数据与关于 → 检查更新
