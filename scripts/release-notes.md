## 本次更新（0.4.2）

### 默认输出模式改为「共享」

0.4.2 起默认走系统混音器。以前默认是「自动（优先独占）」—— 每次开始播放都会先尝试 WASAPI 独占，
不成功再回退共享；现在不再尝试，直接把声音交给系统。

想要 bit-perfect 的，仍然可以在 **设置 → 独占输出 → 输出模式** 里切回「自动」或「独占」，
设备不支持时依旧自动回退共享并说明原因。**已经手动选过输出模式的用户不受影响。**

### 音乐库新增「排序方式」按钮

「音乐库 → 歌曲」工具行右侧多了一枚 **排序方式** 按钮，7 种排法：

| 排序方式 | 说明 |
| --- | --- |
| 标题 | 按标题升序（原行为） |
| 文件大小 | 大的在前 |
| 修改时间 | 文件的修改时间，早的在前 |
| 添加时间 | 进曲库的时间，早的在前 |
| 修改时间降序 | 最近改动的在前 |
| 添加时间降序 | 最近入库的在前 |
| 播放次数 | 听得最多的在前 |

**这个选择会记住**：切到别的页面再回来、甚至重启应用，都还是你选的那一种。
（表头的「标题 / 专辑 / 时长」点击排序仍然可用，两者共用同一套排序。）

### 新增「播放次数」统计

曲目**真正开始播放**时 +1（列表点播、下一首、播完自动续播都算；暂停后继续、拖动进度不算）。
旧版本的曲库在首次启动时会**自动补上这一列**，原有曲目与标签不受影响。

### 顺带说明

- 0.4.1 的**导入提速**（首次扫描 2.60s → 1.47s）在这一版里同样有效。
- 音频内核与 0.4.1 一致：多相 sinc 重采样、WASAPI 独占 + 自动回退、DSD 1-bit 查表解码。

### 支持的格式一览

| 扩展名 | 编码 / 容器 | 解码器 |
| --- | --- | --- |
| .mp3 | MPEG 音频（MP3） | symphonia |
| .flac | FLAC | symphonia |
| .wav | PCM / ADPCM（RIFF） | symphonia |
| .aiff | PCM（AIFF） | symphonia |
| .caf | PCM（CAF） | symphonia |
| .ogg / .oga | Ogg 容器内的 Vorbis | symphonia |
| .m4a / .m4b | MP4 容器内的 AAC 或 ALAC | symphonia |
| .opus | Ogg Opus | opus-pure（自行接入） |
| .aac | 裸 AAC / ADTS 流 | 自写 ADTS 解封装 + symphonia 的 AAC 解码器 |
| .dsf / .dff | DSD | 自研：1-bit 查表低通 + 整数抽取转 PCM |

**暂不支持**：APE、WavPack、TAK、Musepack(MPC)、WMA(ASF)、Speex、RealAudio，以及 CUE 整轨分轨。
