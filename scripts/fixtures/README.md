## lrc-highlight-test.lrc

用法：把这份文件复制到**测试曲目**同目录、改成与测试曲目同名（例如 `test-song.lrc`），
或直接临时指向一首拷贝出来的测试曲目。

覆盖了《不凡》的正式歌词，直到 2026-11-08 才从 FLAC 内嵌 `LYRICS` 标签恢复。
以后需要这类歌词时从这里复制，别改用户曲库里的同名文件。
